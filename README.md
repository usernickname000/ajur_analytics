## О проекте

Десктопное приложение для коммерческого отдела. Принимает выгрузку заказов из CRM (`.xlsx`), строит Excel-отчёт с 20+ листами, HTML-дашборд в браузере и сверяет итоги с данными бухгалтерии. Работает полностью офлайн.

---

## Возможности

- **Анализ периода** — месячная выручка (CRM + внешние доходы) с YoY, топ клиентов/менеджеров/номенклатуры, отрасли, сезонность и кварталы, RFM-сегментация, лояльность, прогноз на следующий месяц, анализ скидок по клиентам/менеджерам/бакетам
- **Сигналы и аномалии** — месячные выбросы (>2σ), трёхмесячный спад, концентрация клиентов, RFM-риски, разрыв между менеджерами
- **Сверка с бухгалтерией** — три среза (всего с программатиком / без программатика + бартер / реклама без мероприятий), сводка по группам с расхождениями в ₽ и %, индикатор в GUI (🟢🟡🔴)
- **Сравнение периодов** — два произвольных файла выгрузки: Δ по менеджерам и клиентам, новые/ушедшие клиенты, сгруппированные графики A vs B
- **Дашборд в браузере** — HTML/Chart.js: KPI, график по месяцам, топ-10 клиентов и менеджеров, отрасли
- **План менеджеров** — факт / план / % / статус ✅⚠❌ прямо в отчёте
- **Папка-наблюдатель** — автозапуск анализа через 5 мин после появления нового `.xlsx`, toast-уведомления
- Графики прямо в Excel, KPI-карточки в GUI

## Файлы конфигурации

| Файл | Назначение | Редактируется |
|------|-----------|----------------|
| `external_income.json` | Внешние доходы по месяцам (программатик, бартер, ИРИ/АНО, рекомендательные системы, e-com, 47News) | GUI **⚙ Внешние доходы**, или импортом из «Доходы ГГГГ.xlsx» (см. ниже) |
| `verified_figures.json` | Верифицированные годовые итоги из бухгалтерии — `total_with_prog`, `total_with_barter_no_prog`, `advertising_no_events`, `programmatic_external`, `other_external_income` | GUI **⚙ Верифицированные цифры** |
| `client_aliases.json` | Правила нормализации клиентов (группа `canonical` ← подстроки `patterns`) | GUI **Алиасы клиентов** |
| `config.json` | Последние пути к файлам, тема, планы менеджеров, базовая дата | создаётся автоматически |

Ключевые служебные поля `external_income.json`: `_год`, `_включать_в_аналитику` (что добавляется к CRM в месячной/сезонной аналитике), `_не_включать_в_grand_total` (закупочные/технические проводки), `_план_группы_по_месяцам_руб`, `_план_KPI_по_месяцам_руб`.

### Импорт «Доходы ГГГГ.xlsx» (`dohody_import.py`)

Читает лист `ДОХОДЫ ГГГГ` мастер-файла бухгалтерии и обновляет `external_income.json` напрямую — без ручной перепечатки цифр:

- пишет только статьи, которых нет в CRM; CRM-статьи (реклама, IC-доходы, СММ) только показывает для сверки;
- сверяет сумму найденного с итоговыми строками файла (`Total Ads/Events/Прочие/Commercial Sales`) и подсвечивает выбросы по месяцам;
- при смене отчётного года бэкапит текущий `external_income.json` и обнуляет ещё не заполненные месяцы (не переносит на них цифры прошлого года).

GUI: **⚙ Импорт Доходы.xlsx** (сначала отчёт, запись — только по «Применить»). Консоль:
```bash
python dohody_import.py "Доходы 2026.xlsx"          # отчёт, без записи
python dohody_import.py "Доходы 2026.xlsx" --apply   # применить
```
Сопоставление «строка файла → каноническая статья» — явный список `RAW_LABEL_MAP` в начале файла; несопоставленные строки видно в отчёте, а не угадываются.

## Входной файл (выгрузка CRM)

**Обязательные колонки:** `Заказ`, `Дата заказа`, `Выручка без НДС`, `Месяц` (`ММ.ГГГГ`/`ММ.ГГ`), `Менеджер`, `Проект`, и хотя бы одно из `Клиент РА` / `Клиент` / `Рекламодатель`.

**Опциональные:** `Скидка, %` (листы 17*), `Бартер` (да/пусто), `ДатаСуммаОплаты_` (`ДД.ММ.ГГГГ СУММА`, сверка по дате оплаты), `Номенклатура`, `Отрасли КлиентаРА`/`Отрасли Клиента` (лист 04).

## Установка и запуск

```bash
pip install -r requirements.txt
python app.py
```

**Сборка в .exe:**
```bash
pip install pyinstaller
python build.py
```
Результат — `dist/АналитикаЗаказов.exe`, конфиг-JSON включены автоматически. При первом запуске Windows Defender может предупредить — «Подробнее → Всё равно запустить».
